# /cheatsheet — Vibe-Coding Quick Reference

Use this skill to view all available slash commands and shortcuts in a clean ASCII card.

1. Run `.agents/bin/vibe_tui.py cheatsheet` to render the reference card.
2. Summarizes primary workflows:
