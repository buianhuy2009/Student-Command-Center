# /explain — Socratic Codebase Explainer

Analyze and explain code structure clearly:
1. **Plain English Walkthrough**: Explain what the targeted file or function does, step-by-step.
2. **Dataflow & State**: Describe where input enters, what store (Zustand) or database (Dexie) updates, and what UI renders.
3. **ASCII Architecture Diagram**: Illustrate relationships using clean ASCII text diagrams (no emojis).
4. **Non-Obvious Design Decisions**: Highlight race condition guards, debounces, error boundaries, or security sanitizers.
