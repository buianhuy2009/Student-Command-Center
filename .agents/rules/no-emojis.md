# No-Emoji Professional Standard

1. **Aesthetic Tone**: All code comments, commit messages, status reports, and terminal outputs must use clean, professional English with standard ASCII or universal technical symbols (`│`, `█`, `░`, `·`, `+`, `-`).
2. **Zero Emojis**: Strictly forbid emojis (e.g. 🧠, ⚡, 📅, 🚀, 💡, 🔥, etc.) in source code, user-facing UI copy, changelogs, documentation, and agent output responses.
3. **Typography**: Prioritize clear, understated developer typography over flashy decorative elements.
