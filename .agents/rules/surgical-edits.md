# Surgical Edits & File Size Discipline

1. **Precision Edits**: Make targeted line replacements. Never rewrite an entire 200+ line file when adding or modifying small functions.
2. **File Size Limit**: Keep React components and service files modular (under 250 lines). Split helper utilities, sub-components, and custom hooks into dedicated files.
3. **Preserve Surrounding Code**: Retain existing unrelated comments, formatting, and docstrings unless explicitly instructed to refactor.
